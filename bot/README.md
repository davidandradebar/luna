# bot

Placeholder para la integración de WhatsApp a través de la infraestructura de AURA (Evolution API).

Alcance previsto:

- Notificar turno asignado, cuadro publicado y recordatorios.
- Registrar preferencias, peticiones e intercambios conversando.
- Reportar novedades y alertar al coordinador.
- Consultas: turno de un día, horas acumuladas.

Requisito previo a cualquier mensaje: consentimiento del empleado para el tratamiento de datos y el canal (Ley 1581).
